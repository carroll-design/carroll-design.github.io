## Overview

Conceptualized, designed, and created a browser-based tool to remove metadata from images also allowing for file type
conversions and image editing. This tool was created in collaboration with Claude AI.

## Identifying the Problem

While creating my portfolio website, I began to upload photos I had taken of various projects. It occurred to me that these photos
contain sensitive information, including the location, time, and even information about the device that took the photo.

## Metadata

There is quite a bit of metadata typically contained in images. These commonly include device info, exposure info, optics info,
image info, date and GPS info, date and time info, and more. For privacy and cybersecurity, the most important of these are the device info,
GPS info, and date and time info.

Device info typically includes the make, model, software, and even serial number. This info can tell us a lot about a device,
and even trace back to the person who owns that device. Given both the software version and date recorded in the metadata,
we can also tell whether the device is out of date, and therefore more at risk from cyber attacks.

someone was, and when they were there.

Cybersecurity is something that should be taken very seriously. If not properly redacted, this info could reveal a person's devices, whereabouts, and even
their home. Not only does this metadata put the photographer at risk, but also anyone else in or around the photo. For example, if you took a photo at a relative's house,
now the location of that house is recorded within the image file.

## The Solution

To resolve this issue, I designed a metadata removal tool. This tool is designed to work in browser and entirely locally, ensuring that files you upload to the program
never leave your computer.

The program allows for the user to upload image files in JPEG, PNG, WebP, AVIF, BMP, and HEIC/HEIF formats.
Once a file is uploaded, the program decodes the image into raw pixels. Then, the entire image is redrawn onto
a blank canvas. This ensures that there are no remnants of the original metadata, as it is now an entirely
new file. Once rewritten, the image or images can be downloaded.

This program allows for the user to quickly and easily scrub image files of any metadata, and even allows
for bulk image scrubbing.

## Additional Capabilities

This program is also capable of converting image files to different file formats. The user can select their format of choice from a dropdown above the upload box.

If the chosen file format is changed, all images uploaded to the program in that session will be rewritten in the new format. By default,
the program will retain the original file format.

The program also allows for the user to edit the image file. Editing functionality includes renaming the file, rotating the image, and cropping
the image.
